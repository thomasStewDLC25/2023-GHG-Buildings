# 2023-GHG-Buildings
To best interact with this map, use the zoom function to get a closer look at the ghg emissions as reported by specific buildings. Greenhouse gas emissions by zip code and building type in Philadelphia PA in 2023. As per opendataphilly.org, there are buildings that a required to report their ghg emissions. Not all may be represented on this map. It is more of an average of each building type and in each Philadelphia zip code and the average and percentage of emissions of those required to report.
